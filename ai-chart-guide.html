AI×チャート

従来のチャートツールとは違い、複雑な分析をAIが自動で行います。感覚的な判断ではなく、**根拠ある投資判断**をサポートします。

💡 このツールについて： AI×チャートは、投資判断をサポートするツールです。最終的な判断は、ユーザー自身の責任で行ってください。過去のパフォーマンスは、将来の成果を保証しません。
📈

① 高性能チャート機能

プロ級の分析ツール × スマホ対応

AI×チャートの基本となるチャート機能です。 複雑なテクニカル分析を、初心者でも直感的に操作できるように設計されています。

🎨 表示形式の切り替え

チャートの表示方法を、用途に応じて自由に変更できます：

✓
ローソク足：始値・高値・安値・終値を一目で確認。プロトレーダー向け。
✓
折れ線チャート：シンプルで分かりやすい。初心者向け。

📸 チャート機能の基本表示

📊 移動平均線（MA）

過去の株価の平均値を線で表示します。トレンドを見つけるのに最適です：

✓
MA1〜MA4：4本の移動平均線を同時表示。短期・中期・長期のトレンドが見える。
✓
ゴールデンクロス：短期MAが長期MAを上回ると、上昇トレンド開始の可能性。

📸 移動平均線（MA1〜MA4）の表示

🔧 テクニカルインジケーター

プロのトレーダーが使う分析ツールを搭載：

✓
MACD：速度が速い移動平均線と遅い移動平均線の差を表示。売買タイミングの判断に。
✓
RSI：買われすぎ・売られすぎを判定。0〜100で表示、70以上で警戒、30以下でチャンス。

📈 出来高バー

その日に何株取引されたかを表示します：

出来高が多い日は、市場の注目度が高い日。大口の資金が動いている可能性があります。

💡 初心者向けTips： まずはローソク足 + 移動平均線（MA1, MA2）だけで十分です。複雑さに慣れてから、MACDやRSIを追加しましょう。
🤖

② AI分析機能

AIが自動で判断、数字で表示

AI×チャートの核となる機能です。 膨大なデータをAIが分析し、感覚ではなく確率で判断をサポートします。

📊 上昇確率 / 下落リスク

AIが過去のチャートパターンと現在の株価を比較し、今後の株価が上がる確率を数字で表示します：

  • 上昇確率 70% 以上： AIが「この形は上昇する傾向が強い」と判定
  • 下落リスク 30% 以上： AIが「これから下げる可能性がある」と警告

これらの確率は、40年分のデータから学習した結果です。「なんとなく」ではなく、統計的根拠があります。

📸 AI分析：上昇確率・下落リスク表示

📈 トレンド強弱の判定

現在のトレンドが「強いのか」「弱いのか」を判定：

  • 強気トレンド： 上昇が続く可能性が高い → 買い目線
  • 弱気トレンド： 下落が続く可能性が高い → 売り目線
  • 中立： 方向が定まらない → 様子見推奨

🎯 相場状態の分類

AIが現在の相場を、以下のいずれかに分類します：

  • 上昇相場： 堅調な買いが続いている
  • 下落相場： 売り圧力が強い
  • レンジ相場： 上下の値動きが小さく、一定の範囲で推移
  • ボラティリティ期： 急騰・暴落など、予測不可能な変動
📌 重要な注意： AI分析は確率であり、100% 的中するわけではありません。参考情報として活用し、必ず自分自身で判断してください。
🔮

③ 未来予測ゾーン

チャート右側に「あり得る未来」を可視化

これは AI×チャート最大の特徴です。 チャートの右側に、AIが推定した将来の株価レンジを表示します。

📊 3本のラインで将来を表示

  • 上限ライン（オレンジ）： 株価が上昇する可能性がある上限
  • 中央ライン（ゴールド）： 最も可能性が高い価格帯
  • 下限ライン（赤）： 下落する可能性がある下限

この3本の線で囲まれたゾーンが、「あり得る未来」のレンジです。

📸 未来予測ゾーン：チャート右側に将来の可能性を表示

⚙️ ボラティリティの反映

ボラティリティ（値動きの激しさ）に応じて、予測ゾーンの幅が変わります：

  • ボラティリティが高い： ゾーンが広い → 値動きが大きくなる可能性
  • ボラティリティが低い： ゾーンが狭い → 値動きが小さくなる可能性
💡 使い方のコツ： 未来予測ゾーンは、「確実な値」ではなく「可能性のレンジ」です。投資目標の設定や、損切り価格の決定に役立てましょう。
📊

④ モンテカルロ予測シミュレーション

数千パターンのシミュレーションで確率を算出

モンテカルロ法とは、統計学の手法です。 コンピュータが何千・何万というシミュレーションを行い、最も可能性の高い将来を計算します。

🎲 シミュレーションの仕組み

AIが過去の株価変動パターンを学習し、現在の状況から以下を計算：

  • 明日：7,000パターンのシミュレーション
  • 1週間後：5,000パターンのシミュレーション
  • 1ヶ月後：3,000パターンのシミュレーション

これらの結果から、「上昇する確率は70%、下落する確率は30%」という確率を導き出します。

📸 モンテカルロ予測：複数パターンのシミュレーション結果

📌 重要： 過去のパターンに基づくため、市場に大きな変化（経済危機など）があると、シミュレーション精度は低下します。
🔥

⑤ セクター資金分析

業種全体の資金の流れを可視化

日本の株式市場は、33の業種（セクター）に分かれています。 このツールは、各業種への資金の流れをリアルタイムで表示します。

🌡️ ヒートマップ表示

色分けで資金の流れを一目で把握：

  • 赤（ホット）： 資金が集中している業種 → 上昇トレンド
  • 青（コールド）： 資金が流出している業種 → 下落トレンド
  • 灰色（ニュートラル）： 買い売りが均衡

📸 セクター分析：33業種のヒートマップ表示

💰 資金流入 / 流出の追跡

大口の投資家がどの業種に投資しているか分析：

  • 例：銀行・証券業が赤い → 景気好転を予想する大口が買っている
  • 例：IT・通信業が青い → テック企業を避ける動きか
💡 活用法： 個別銘柄を選ぶときは、その企業が属する業種の動きも確認しましょう。業種全体が上昇トレンドなら、その中の銘柄は比較的買いやすいです。

⑥ ランキング機能

最も強い銘柄を即座に発見

6000銘柄すべてを自動分析し、複数のランキングで表示します。 これにより、投資機会を見落としません。

📊 複数のランキング視点

✓
上昇率ランキング： 過去1日、1週間、1ヶ月で最も上昇した銘柄
✓
出来高ランキング： 最も取引が多い銘柄 → 大口が動いている
✓
資金流入ランキング： 最も買い圧力が強い銘柄
✓
AI評価ランキング： AIが「買い」と判定した上位銘柄

📸 ランキング機能：複数の視点で銘柄を発掘

⚠️ 注意： ランキング上位だからといって、必ず上昇するわけではありません。ランキングはあくまで参考です。各銘柄の詳細をチェックしましょう。
🔍

⑦ 類似チャート検索

過去の同じ形を探して、その後を予想

「同じ形のチャートの後は、同じように値動きする」という仮説に基づいています。 AIが自動で過去の似たチャート形を検出し、その後の値動きを参考として表示します。

🔎 検索の仕組み

  • ステップ1： AIが現在のチャート形を分析
  • ステップ2： 過去40年のデータから「似た形」を検索
  • ステップ3： マッチした形の「その後の値動き」を表示
  • ステップ4： 複数の類似例があれば、確率で判定

📸 類似チャート検索：過去の似た形を自動検出

📈 活用例

例えば、現在のチャートが「ダブルボトム」という形だったとします：

  • 過去40年で同じ「ダブルボトム」は100回発生
  • そのうち、70回は上昇、30回は下落
  • → このパターン後の上昇確率は70%
💡 使い方： 「この形は上昇する傾向」という確率的な根拠が得られます。これを他の分析と組み合わせることで、判断の精度が上がります。
⚡

⑧ AI検出機能

プロの分析を完全自動化

プロのトレーダーが手作業で行う分析を、AIが自動検出します。 チャンスや危機を見落としません。

🚨 暴落検出

AIが「この株は暴落する可能性がある」と判定した場合、アラート表示：

  • 売り圧力が極端に強い
  • 出来高が異常に多い（大口の売却）
  • テクニカル指標が過度な悪化を示している

📸 AI検出機能：暴落検出・ブレイクアウト検出

📈 ブレイクアウト検出

AIが「この株は上昇ブレイクアウトの寸前」と判定した場合、チャンスアラート：

  • 長期的な抵抗線を突破しようとしている
  • 買い圧力が増している
  • 出来高が上昇している

📊 サポート / レジスタンス自動生成

チャート上に、自動的に重要な価格レベルが表示：

  • サポート（支持線）： この価格で反発する傾向がある下値
  • レジスタンス（抵抗線）： この価格で売られる傾向がある上値

💼 出来高壁（大口検出）

大口の投資家が仕込んでいる価格帯を自動検出：

  • 過去に大量に取引された価格帯が強く表示
  • 大口が注目している価格だから、上昇・下落の転換点になりやすい
📉

⑨ 日経比較（ベンチマーク）

個別銘柄 vs 日経225で実力を判定

「この銘柄は市場全体より強いのか？弱いのか？」を判定するツールです。 日経平均（日経225）をベンチマークとして、個別銘柄のパフォーマンスを比較分析します。

📊 日経vs個別銘柄の比較表示

同じチャート上に2つの値動きを重ねて表示：

  • 日経225（青線）： 日本全体の株価指数。市場全体の動き
  • 個別銘柄（オレンジ線）： 注目している銘柄の値動き

2つの線を比較することで、その銘柄が「市場全体より上昇しているのか」「下落しているのか」が一目でわかります。

📸 日経比較：個別銘柄 vs 日経225

📈 相対パフォーマンスの分析

AIが自動で以下を計算・表示：

✓
アウトパフォーマンス率： この銘柄が日経より強い確率。70%以上あれば、相場全体より強い銘柄
✓
相対強度（RS）： 銘柄値段 ÷ 日経225で計算。上昇 = 相対的に強い
✓
ベータ値： 日経が1%上昇したとき、この銘柄は何%上昇するか。大きいほどハイリスク・ハイリターン

🎯 実践的な活用シーン

シーン1：強気市場での銘柄選び

  • 日経225が上昇している相場で
  • さらにこの銘柄のアウトパフォーマンス率が70%以上なら
  • → 「市場全体より強い銘柄」=買いチャンス

シーン2：弱気市場での防御

  • 日経225が下落している相場で
  • この銘柄だけがアウトパフォーマンスしている（赤線が上向き）なら
  • → 「市場から資金が逃げても買われている」=強い銘柄

⚠️ ベータ値の読み方

ベータ値はリスク・リターンの指標です：

  • ベータ = 1.0： 日経と同じペースで上下。市場平均的なリスク
  • ベータ > 1.0： 日経より激しく上下。上昇時は儲けやすいが、下落時は損失も大きい（ハイリスク）
  • ベータ < 1.0： 日経より穏やかに上下。安定的だが、上昇余地も限定的（ローリスク）
💡 活用のコツ： 日経比較は「この銘柄は市場から評価されているか」を判定するツールです。アウトパフォーマンス率が高い銘柄を、他の分析（AI分析、未来予測）と組み合わせると、より確度の高い投資判断ができます。
📌 重要な視点： 「日経より強い = 必ず上昇する」ではありません。むしろ「市場全体との相対的な強さ」を理解することが大切です。例えば、日経が年50%下落しているときに、この銘柄が年20%下落していれば、相対的には「強い銘柄」です。
🔀

⑩ 個別銘柄比較チャート

複数の銘柄を同時に分析・比較

2〜5つの銘柄を同じチャート上に重ねて表示し、値動きを比較するツールです。 類似企業の相対的な強さや、セクター内での優劣を一目で判定できます。

📊 複数銘柄の並列表示

最大5銘柄まで、同じチャート上に表示可能：

  • 銘柄A（赤線）、銘柄B（青線）、銘柄C（黄線）... など、色分けして表示
  • 期間（日足・週足・月足）を自由に選択
  • 移動平均線やインジケーターも各銘柄ごとに表示可能

📸 個別銘柄比較：最大5銘柄の同時表示

🎯 活用シーン①：セクター内での相対比較

例：自動車業界の大手3社を比較

  • トヨタ（1234）vs ホンダ（1267） vs 日産（1268）
  • 同じセクターでも、値動きが異なることがわかる
  • → 「この3社の中で、今最も強い銘柄はどれか？」が一目瞭然

見分け方：

  • グラフが上にある銘柄 = より強いパフォーマンス
  • グラフが下にある銘柄 = より弱いパフォーマンス

🎯 活用シーン②：類似企業の力関係把握

例：IT企業の成長比較

  • ソフトバンクグループ（9984）vs GAFAM関連銘柄
  • 国内IT企業 vs 海外IT企業の強さを比較
  • → 「今はどの企業が買われているのか？」が判定できる

🎯 活用シーン③：市場トレンド追跡

例：銀行セクター全体の動き

  • メガバンク3社（三菱UFJ, みずほ, 三井住友）を同時表示
  • 3社が全て上昇 → 銀行セクター全体が買われている
  • 1社だけ下落 → その銀行固有の問題がある
  • → 「セクター全体なのか、企業個別なのか」が判定できる

📈 パフォーマンス統計の自動表示

AIが各銘柄のパフォーマンスを自動計算・表示：

✓
過去1ヶ月の上昇率： A銘柄 +15%, B銘柄 +8%, C銘柄 -2%
✓
ボラティリティ（変動性）： どの銘柄がより激しく変動しているか
✓
相関係数： 2つの銘柄の値動きがどれほど連動しているか
✓
ドローダウン（最大損失）： ピークからどこまで下げたか

⚙️ 相関係数の読み方

2つの銘柄の値動きの「連動度」を示します（-1〜+1）：

  • 相関係数 = +1： 2つの銘柄が完全に同じ値動き。分散投資にならない
  • 相関係数 = +0.7〜0.9： 強く連動している。セクター内の銘柄によくある
  • 相関係数 = +0.3〜0.6： 中程度に連動。バランスの取れた分散投資
  • 相関係数 = 0： 全く無関係な値動き。理想的な分散投資
  • 相関係数 = -1： 完全に反対の値動き。最高のヘッジ
💡 アクティブ投資家向けTips： 複数銘柄を比較すると、「相対的な強さ」が見える。セクター全体が上昇していても、その中で「最も強い銘柄」を見つけることで、より高いリターンが期待できます。
⚠️ 注意： 過去の相関係数が高いからといって、将来も同じパターンが続くとは限りません。市場環境の変化で相関が崩れることもあります。定期的に相関係数を確認しましょう。

🎓 初心者向け使用例

Step 1：興味のあるセクターを選ぶ

例：「AI関連企業に投資したい」→ AI関連銘柄3〜4社を選択

Step 2：チャートで比較

過去3ヶ月の値動きを比較 → 「この銘柄が最も強いな」と判定

Step 3：相関係数をチェック

選んだ銘柄の相関係数が +0.8以上なら → 「リスク集中」→ 異なるセクターも買う

Step 4：買付

個別分析（AI分析、未来予測）も合わせて確認して、買付判断

💡 ポートフォリオ構築のコツ： 複数銘柄を比較して、相関係数が低い銘柄を組み合わせることで、リスクを分散しながらリターンを狙えます。これが「分散投資」の基本です。
